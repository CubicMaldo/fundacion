# Catálogo académico navegable FUNASF

## Objetivo

Tomar como referencia la organización académica de Elyon Yireh —sin copiar su identidad ni sus textos— para que una persona pueda avanzar desde la página principal hasta un área de formación, elegir un programa y consultar su página individual.

## Implementación

- Reorganizar **Estudia con FUNASF** como entrada al catálogo: buscador, filtros por área, tarjetas enlazadas y acceso claro a becas, requisitos e inscripción.
- Crear una página de **programas** que reúna toda la oferta oficial ya entregada por FUNASF y permita explorarla por categorías.
- Crear una página individual para cada programa oficial con nombre, área, descripción institucional común, modalidades sujetas a disponibilidad, proceso de inscripción, becas y responsabilidades de la institución aliada.
- Mantener como **pendiente** cualquier dato específico no suministrado: duración, precio, plan de estudios, horarios, requisitos particulares, institución certificadora y fechas. No se copiarán esos datos del sitio de referencia ni se inventarán.
- Actualizar el menú, la página principal y los llamados a la acción para formar el recorrido: **Inicio → Estudia → Área → Programa → Inscripción/contacto**.
- Conservar la dirección visual actual de FUNASF y su paleta verde, marrón, dorado y blanco; la referencia se usará para jerarquía y funcionamiento, no como copia visual.

## Detalles técnicos

- Rutas independientes y compartibles para el catálogo y cada programa, con metadatos propios.
- Identificadores estables para las páginas de programa y navegación interna con enlaces reales.
- Búsqueda y filtros en el navegador, sin añadir base de datos ni panel administrativo.
- Componentes reutilizables para tarjetas, migas de navegación y avisos de información pendiente.
- Validación en computador y celular de todos los programas, menús y enlaces de inscripción.

## Límite de fidelidad

Se replicará la profundidad del recorrido y las funciones públicas aplicables a FUNASF. No se copiarán contenido, marcas, credenciales, datos académicos ni funciones privadas del portal de la institución de referencia.
